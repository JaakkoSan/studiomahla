TOTP-käyttöönotto
Huomio: Tämä sivu generoi uuden TOTP-secretin joka kerta käytettäessä. Avaa tämä vain käyttöönotossa tai laitteen vaihdossa. Poista tämä sivu (admin-setup-totp.html) ja vastaava API (api/setup-totp.js) GitHub-repostasi käyttöönoton jälkeen.

Authenticator-sovelluksen käyttöönotto

Tämä sivu generoi sinulle Authenticator-sovellukseen sopivan QR-koodin ja salaisen avaimen. Aloita antamalla nykyinen admin-salasana.

Käyttöönotto-ohjeet

Seuraa askeleita järjestyksessä. Pidä tämä välilehti auki kunnes olet valmis.

Huom: TOTP_SECRET on jo asetettu Verceliin. Jos jatkat ja korvaat sen, vanha Authenticator-merkintä lakkaa toimimasta.
1
Avaa Authenticator-sovellus puhelimellasi (Google Authenticator, Microsoft Authenticator, Authy, 1Password — mikä tahansa TOTP-yhteensopiva).
2
Lisää uusi tili skannaamalla QR-koodi alta. Jos et voi skannata, syötä alla oleva manuaalinen koodi sovellukseen.
3
Kopioi tämä sama secret Verceliin ympäristömuuttujana TOTP_SECRET. Mene Vercel-projekti → Settings → Environment Variables → Add.
4
Deploy uudelleen Vercelissä jotta uusi env-muuttuja tulee käyttöön. (Deployments → uusin → ⋯ → Redeploy.)
5
Testaa kirjautumalla osoitteessa admin.html — annettuasi salasanan, syötä Authenticator-sovelluksen 6-numeroinen koodi.
6
Poista tämä sivu ja sen API GitHub-repostasi: poista tiedostot admin-setup-totp.html ja api/setup-totp.js, sitten push.
